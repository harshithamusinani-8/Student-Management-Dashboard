# 🎓 Student Management Dashboard

A modern and responsive **Student Management Dashboard** developed as part of my **SkillNexis Internship – Week 4, Assignment 1**.

The application provides an intuitive interface to manage student records, track enrollment statistics, filter students, and export student data.

---

## 📌 Project Overview

The Student Management Dashboard is designed to simplify student record management through a clean and professional admin dashboard.

It supports basic **CRUD operations** along with search, filtering, analytics, course-wise breakdowns, and data persistence using browser LocalStorage.

---

## ✨ Features

### 👨‍🎓 Student Management
- Add new students
- Edit existing student records
- Delete student records
- View student details
- Track Active and Inactive students

### 🔍 Search & Filters
- Search students by:
  - Name
  - Student ID
  - Email
- Filter students by course
- Filter students by status

### 📊 Dashboard Analytics
- Total Students
- Active Students
- Inactive Students
- Total Courses
- Student overview chart
- Course-wise student breakdown

### 💾 Data Persistence
- Student data is stored using **Browser LocalStorage**
- Data remains available even after refreshing the page

### 📁 Report Generation
- Export student records as a **CSV file**
- Generate reports directly from the dashboard

### 🎨 User Interface
- Professional admin dashboard design
- Responsive layout
- Interactive modal form
- Toast notifications
- Clean navigation and dashboard cards
- Mobile-friendly design

---

## 🛠️ Technologies Used

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling, responsive design and animations
- **JavaScript (ES6+)** – Application logic and interactivity
- **LocalStorage** – Client-side data persistence
- **Font Awesome** – Icons
- **Google Fonts** – Typography
